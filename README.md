#barbearia-estilo-fino

Landing page desenvolvida para uma barbearia fictícia/local, com foco em apresentar serviços, valores e localização de forma moderna e responsiva.

## 📋 Sobre o Projeto

Site institucional de página única (one-page) criado para a **Barbearia Estilo Fino**, localizada no centro de Americana. O objetivo é apresentar os serviços oferecidos, a proposta da barbearia, trabalhos realizados e facilitar o contato/agendamento dos clientes.

## ✨ Funcionalidades

- **Header fixo (sticky)** com navegação suave entre seções
- **Seção de Serviços** com cards em grid responsivo (corte, barba, sobrancelha, luzes, etc.)
- **Seção Quem Somos** com a proposta e valores da barbearia
- **Galeria de trabalhos realizados**
- **Seção de Contato** com telefone e endereço
- **Mapa integrado (Google Maps)** mostrando a localização
- **Design escuro e elegante**, com tons de preto e dourado (#d4af37)
- **Efeitos de hover e transições suaves** em botões, links e imagens
- Totalmente **responsivo** para dispositivos móveis

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura semântica da página
- **CSS3** — estilização, grid, flexbox, animações e responsividade
- **Google Maps Embed** — mapa de localização

## 📁 Estrutura do Projeto

```
barbearia-estilo-fino/
├── index.html          # Estrutura da página
├── style.css            # Estilos visuais
├── background.jpg       # Imagem de fundo (adicionar)
└── serviços realizados.png  # Imagem da galeria (adicionar)
```

> ⚠️ As imagens (`imagemdefundo.jpg` e `serviços realizados.png`) precisam estar na mesma pasta dos arquivos HTML/CSS para que apareçam corretamente.
